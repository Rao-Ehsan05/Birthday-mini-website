
# 🎂 Birthday Design

A Flask-based interactive birthday website designed to create a personalized birthday celebration experience.

## ✨ Features

- 🎂 Personalized birthday page
- 📸 Photo uploads
- 🎥 Video uploads
- ⏳ Birthday countdown
- 🎵 Birthday music
- 🎈 Balloon and celebration animations
- 🤲 English and Urdu birthday prayers
- 💖 Beautiful memories gallery
- 💾 Save birthday file
- 🔄 Create another birthday

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask

## 📁 Project Structure

- `app.py` — Flask backend
- `templates/` — HTML files
- `static/` — CSS, JavaScript, images, and audio

## 🚀 How to Run

1. Install Python.
2. Install Flask:
   `pip install flask`
3. Run the application:
   `python app.py`
4. Open the local website in your browser.

## 🎉 About

Birthday Design is a simple personalized birthday website created to turn birthday memories, photos, videos, prayers, and music into a beautiful digital celebration.
